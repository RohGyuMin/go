# 마이크로월드 — BFS 탐험 월드 (아바타형)

같은 BFS를 **"읽는 디버거"가 아니라 "들어가서 겪는 세계"**로 만든 버전입니다.
그래프를 하나의 지도/월드로 렌더링하고, 사용자는 **아바타를 직접 조종**해 자유롭게 돌아다니며,
탐색(BFS)은 그 세계에서 퍼져나가는 사건으로 **목격**합니다.

![preview](preview.png)

## 공유 문서형 vs 아바타/월드형

| | `../bfs/` (문서형 디버거) | `bfs-world/` (아바타/월드형) |
|--|--|--|
| 시점 | 위에서 내려다보는 관찰자 | 세계 안에 **존재하는 아바타** |
| 상태 | 다이어그램 + 표 | 돌아다니는 **공간/장소** |
| 조작 | 타임라인 스크럽 | 자유 이동 + 탐색 목격 |
| 이해 | 읽고 분석 | 겪고 감각 |

두 파일 모두 **같은 `trace.json`**(41 스냅샷)을 재료로 씁니다 — 데이터는 같고, *경험*이 다릅니다.

## 바로 체험
`index.html`을 브라우저로 더블클릭 (trace 인라인 임베드 → 서버 불필요).

- **이동**: `W A S D` 또는 화살표 (카메라가 아바타를 따라감)
- **탐색 재생**: `Space` 또는 `▶ 탐색 재생` (BFS가 시간에 따라 세계로 퍼짐)
- **스텝**: `[` `]` 또는 슬라이더 스크럽
- **리셋**: `R`
- 아바타로 장소에 다가가면 안개가 걷히며 발견 · 우하단 미니맵으로 전체 조망

장소 색: 회색(미발견·안개) → 주황(큐 대기) → 파랑(현재) → 초록(확정).

## 다른 대상에 적용
`trace_bfs.py`류의 계측으로 `trace.json`을 만들고, `NODES` 좌표와 `drawPlace()`/`render()`를
대상 세계에 맞게 바꾸면 됩니다. (상태머신=방들, 이벤트 루프=흐르는 강, 정렬=탑 쌓기 등)

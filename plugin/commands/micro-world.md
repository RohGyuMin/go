"코드를 읽는 대신 감각적으로 이해"하도록 돕는 마이크로월드를 만듭니다.
대상: **$ARGUMENTS** (비어 있으면 무엇을 관찰하고 싶은지 물어보세요.)

## 절차

1. **대상 파악**: `$ARGUMENTS` 코드를 읽고, 시간에 따라 변하는 "상태"(변수·자료구조·큐·커서 등)를 식별합니다.

2. **추적 계측(trace) 제안**: 핵심 지점에서 상태 스냅샷을 남기는 최소 코드를 작성합니다.
   각 스냅샷은 아래 JSON 라인. 프로덕션 오염 방지를 위해 환경변수 플래그(예: `MICROWORLD_TRACE=1`)로 감쌉니다.
   ```json
   {"step": 0, "label": "init", "state": { }, "note": "설명"}
   ```

3. **마이크로월드 생성**: 플러그인 번들 템플릿을 프로젝트로 복제합니다.
   ```
   !mkdir -p microworlds && cp -r "${CLAUDE_PLUGIN_ROOT}/templates/micro-world" "microworlds/<slug>"
   ```
   - `index.html`은 자체 완결형(단일 파일, 외부 CDN 불필요)이며 타임라인 슬라이더로 스텝을 스크럽합니다.
   - 계측이 만든 `trace.json`(스냅샷 배열)을 `microworlds/<slug>/trace.json`으로 두면 로드됩니다.
   - 상태 렌더링(`drawViz`)을 대상에 맞게 커스터마이즈합니다(배열→막대, 그래프→노드, 상태머신→하이라이트 등).

4. **실행 안내**: (a) 계측을 켜고 대상을 실행해 `trace.json` 생성, (b) `microworlds/<slug>/index.html`을
   브라우저로 열어 타임라인 스크럽. 목표는 **슬라이더를 드래그하며 내부 상태 변화를 직접 조작**해 이해하는 것.

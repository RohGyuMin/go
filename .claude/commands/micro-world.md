당신은 "코드를 읽는 대신 감각적으로 이해"하도록 돕는 마이크로월드를 만듭니다.
대상: **$ARGUMENTS** (비어 있으면 사용자에게 무엇을 관찰하고 싶은지 물어보세요.)

## 절차

1. **대상 파악**: `$ARGUMENTS`에 해당하는 코드를 찾아 읽습니다. 어떤 "상태"가 시간에 따라 변하는지
   (변수, 자료구조, 이벤트 큐, 커서/포인터 등) 식별합니다.

2. **추적 계측(trace) 제안**: 대상 코드의 핵심 지점에서 상태 스냅샷을 남기는 최소한의 추적 코드를 작성합니다.
   각 스냅샷은 아래 형태의 JSON 라인으로 남깁니다.
   ```json
   {"step": 0, "label": "init", "state": { ... }, "note": "설명" }
   ```
   프로덕션 코드를 오염시키지 않도록 환경변수 플래그(예: `MICROWORLD_TRACE=1`)로 감쌉니다.

3. **마이크로월드 생성**: `templates/micro-world/`를 `microworlds/<slug>/`로 복제합니다.
   - `index.html`은 자체 완결형(단일 파일, 외부 CDN 불필요)이며 타임라인 슬라이더로 스텝을 스크럽합니다.
   - 계측이 만든 `trace.json`(스냅샷 배열)을 로드해 각 스텝의 상태를 시각화합니다.
   - 상태 렌더링은 대상에 맞게 커스터마이즈합니다(배열→막대, 그래프→노드, 상태머신→하이라이트 등).

4. **실행 안내**: 사용자에게 (a) 계측을 켜고 대상을 실행해 `trace.json`을 만드는 법,
   (b) `microworlds/<slug>/index.html`을 브라우저로 열어 타임라인을 스크럽하는 법을 안내합니다.

핵심 목표: 사용자가 **슬라이더를 드래그하며 내부 상태가 어떻게 바뀌는지 직접 조작**하여
시스템 메커니즘을 직관적으로 이해하게 하는 것입니다.

# 설명 문서 보관소

`/explain-diff` 로 생성된 종합 설명 문서(+ 5문항 퀴즈)가 여기에 쌓입니다.

- 파일명 규칙: `<YYYY-MM-DD>-<slug>.md` (예: `2026-07-21-auth-refactor.md`)
- 템플릿: [`../../templates/explanation.md`](../../templates/explanation.md)
- CI 게이트(`.github/workflows/explanation-check.yml`)는 코드가 바뀐 PR에
  이 폴더의 문서가 동반되는지 확인합니다.

이 문서들은 팀의 "이해 자산"입니다. 축 3(공유 공간)에서 리뷰 재료로 활용하세요.
